Üz uyğunluğu həddi

Həddi artırmaq yanlış uyğunluqları azalda, həqiqi şəxslərin rəddini artıra bilər. Seçimi ayrı test nümunələri ilə ölç.

Məlumat və giriş qorunması

  • Şifrəli biometrik nümunələr
  • Müddətli administrator sessiyası
  • CSRF və eyni origin yoxlaması
  • Sorğu ölçüsü və sürət limitləri
  • İdarəetmə əməliyyatları jurnalı

Yalnız localhost. Açarlar eyni kompüterdə saxlanır; kompüterə tam girişdən müdafiə deyil.

Problem həlli ardıcıllığı

Kamera açılmır?Windows və brauzer kamera icazəsini yoxla. Kameranı tutan başqa tətbiqi bağla.

Serverə əlaqə yoxdur?Proses → dinlənilən port → firewall → IP/VLAN → marşrut ardıcıllığı ilə araşdır.

Üz uyğun gəlir, giriş yoxdur?Hesabın aktivliyini, giriş nöqtəsini və Bakı vaxtı ilə cədvəli yoxla.

Model və ya baza xətası?Server terminalını və scripts/diagnose.py nəticəsini yoxla. Xətanı həddi azaltmaqla gizlətmə.
